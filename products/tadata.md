# Tadata

**创新评分：★★★★★**  
**模式：Observe → Detect Pattern → Propose Automation**

## 真实问题
自动化工具越来越强，但最大问题仍然是：普通人往往不知道自己哪些工作值得自动化，也不会主动建 workflow。

## 旧工作流
用户先意识到重复工作 → 主动打开 n8n/Zapier/脚本 → 描述或配置流程 → 自动化执行。

## 新工作流
AI观察正常工作 → 识别重复模式 → 推断潜在自动化机会 → 主动提出建议 → 人确认后再生成/执行自动化。

## 核心机制
创新不在执行自动化，而在 **Process Discovery**。AI先发现“应该自动化什么”。

## Composable Test
CLI + cron 能执行，但不能天然发现机会。因此它改变的是自动化系统的起点。

## 可迁移原则
> 自动化产品下一步不是让 Workflow Builder 更简单，而是让系统主动发现值得自动化的流程。

## 对本地 Agent / B/G 的启发
本地 Agent 可以观察重复的浏览器操作、CLI、文件处理和业务步骤，形成“自动化候选”，再由人批准将稳定部分编译成脚本/规则。

## 跟踪判断
**核心基准产品。**
