# Atlas

**创新评分：★★★★☆**  
**模式：Organization Context Layer**

## 真实问题
企业里每个 Agent 若分别维护自己的 Prompt、知识库和业务规则，会快速出现口径冲突和重复配置。

## 核心机制
把公司规则、术语、业务约束、组织知识抽离成共享 Context Layer，多 Agent 使用同一权威上下文。

## 为什么不是普通知识库
关键不在“检索更多文档”，而是建立组织级 Context 的权威来源和复用边界。

## 可迁移原则
> Agent 可以很多，但组织语义和规则不应该每个 Agent 各自维护一份。

## 对 B/G 的启发
组织架构、主体归属、风险定义、周期任务规则、隐患状态机等应形成统一权威层，所有专家/督办/验收 Agent 引用它，而不是在 Prompt 中复制规则。

## 不确定性
真正难点是版本、生效时间、权威性和例外，而不是 RAG 技术。

## 跟踪判断
**非常适合企业/BG Context 架构参考。**
