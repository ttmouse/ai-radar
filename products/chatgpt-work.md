# ChatGPT Work

**创新评分：★★★★★**  
**模式：Goal → Autonomous Work**

## 真实问题
传统聊天模型每一步都需要用户继续发 Prompt，复杂任务中人实际上承担了流程编排、文件切换、检查结果和下一步决策。

## 新工作流
用户交付目标和约束 → Agent 持续研究、处理文件、使用工具、跨应用执行 → 在关键节点请求人判断 → 输出可交付成果。

## 核心机制
从“对话回合”切换到“工作任务”。用户管理的是 outcome，不再管理每一步操作。

## 为什么不是普通加 AI
不是聊天框变强，而是产品的基本对象从 Message/Conversation 变成 Work/Task/Artifact。

## Composable Test
底层 browser/tool use 可以拼装，但持续任务状态、云端工作环境、权限与产物交付共同构成新的产品形态。

## 可迁移原则
> AI 产品应尽量让用户委派结果，而不是让用户人工编排模型的每一步。

## 对本地 Agent 的启发
本地 Agent 的任务应有明确目标、接受标准、Context、Tools、状态、Artifacts、Checkpoint，而不是只保留聊天记录。

## 跟踪判断
**基础范式级产品。**
