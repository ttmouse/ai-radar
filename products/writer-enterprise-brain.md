# WRITER Enterprise Brain

**创新评分：★★★★☆**  
**模式：Organization Learning Loop**

## 真实问题
企业 Agent 常靠静态知识库工作，但组织真实知识存在于会议、Slack、决策、修订、例外处理和日常操作里。如果不持续学习，Context 很快过时。

## 核心机制
把组织日常工作中的决策与上下文持续沉淀成团队级可复用 Context，让后续 Agent 使用，而不是每次从零开始或只检索文档。

## 为什么不是普通 RAG
RAG 主要解决“找已有文档”；Organization Learning Loop 试图解决“组织刚刚学到了什么，以及这个知识以后是否应该继续生效”。

## 最大难题
必须区分随口讨论 vs 正式决定、个人偏好 vs 组织规则、旧政策 vs 当前政策。否则 Memory 会迅速变成 context garbage。

## 可迁移原则
> 企业 Memory 的关键不是存得多，而是知道什么值得成为组织长期状态。

## 对本地 Agent / B/G 的启发
应急项目里的检查口径、专家判断、领导确认和规则修订可以沉淀为不同等级的知识对象，但必须保留来源、生效时间、责任人和权威级别。

## 跟踪判断
**值得跟踪，但重点看治理而非“记忆更多”。**
