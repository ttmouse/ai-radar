# Claude Cowork

**创新评分：★★★★☆**  
**模式：Goal → Autonomous Work**

## 核心判断
价值不在“Claude 会做更多工具调用”，而在从一次性答复转向持续工作：用户给出目标，Agent 在工作空间中推进任务，在真正需要判断时再让人介入。

## 工作流变化
传统：人拆步骤 → AI逐步回答 → 人搬运结果。  
新：人定义目标/边界 → Agent 自主推进 → 关键节点 Human-in-the-loop → 交付 artifact。

## Composable Test
与 ChatGPT Work 属于同一大模式，因此不单独创造新产品原理。差异更可能体现在执行环境、工具生态、权限和协作体验。

## 可迁移原则
> 当 Agent 足够能执行时，人机界面应该围绕目标、状态、例外和验收，而不是 Prompt 历史。

## 对本地 Agent 的启发
任务看板的关键不是“AI认领卡片”，而是卡片背后能恢复完整执行状态、接受标准与产物，让 Agent 可以中断、继续、退回和重试。

## 跟踪判断
**继续跟踪，但不重复计为新模式。**
