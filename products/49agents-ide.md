# 49agents IDE

**创新评分：★★★★☆**  
**模式：Spatial Agent Supervision**

## 真实问题
当一个人同时监督几十个 Agent、代码库、机器或任务时，传统 Tab、列表、聊天线程很快失去可见性。真正的瓶颈变成人的空间记忆与注意力调度。

## 核心机制
用无限画布/空间布局表达 Agent、任务、机器与状态，让人通过位置和聚类理解“谁在做什么、哪里卡住、哪里需要介入”。

## 为什么不是普通加 AI
AI 能力不是重点；重点是为多 Agent 工作重新发明监督界面。

## Composable Test
画布技术本身很成熟，但当空间关系承担工作状态和注意力路由时，已经改变了 Agent 操作界面原语。

## 可迁移原则
> 多 Agent 时代，列表可能不是最好的监督结构；空间可以成为认知索引。

## 对本地 Agent / B/G 的启发
未来若一个专家同时监督多个企业、任务和 Agent，可以考虑 Queue View、Object View、Agent View 三种视角，而不是把一切都塞进聊天与菜单。

## 跟踪判断
**值得跟踪，尤其是多 Agent UI。**
