# Accordio

**创新评分：★★★★★**  
**模式：Agent-facing System of Record**

## 真实问题
Agent 可以写邮件、合同和分析，但如果不知道真实客户、费率、工时、合同状态、欠款和历史交易，它仍然只是“聪明的文本工具”。

## 核心机制
Accordio 保存可信业务状态和确定性规则，并通过 MCP 暴露给 Agent。Agent 成为主要意图入口，但真实状态、计算、交易和高风险动作仍由业务系统负责。

## 新工作流
用户表达意图 → Agent读取真实业务状态 → 业务系统执行确定性计算 → Agent生成 proposal/draft → 人确认高责任动作 → 系统执行并记账。

## 为什么不是普通加 AI
不是 SaaS 加聊天框，而是 UI 与 System of Record 开始解耦：Agent 可以成为前台，SaaS 退到底层状态、规则、权限与交易。

## 可迁移原则
> 很多 SaaS 的长期价值可能不再是 UI，而是给 Agent 提供可信状态和确定性动作。

## 对 B/G 的启发
企业、隐患、任务、整改、组织和责任关系继续由确定性业务系统维护；Agent负责理解、发现、推理和建议。后台可逐渐成为 Agent 背后的 Business Runtime。

## 跟踪判断
**最高价值样本之一。**
