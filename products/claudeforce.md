# Claudeforce

**创新评分：★★★★☆**  
**模式：Headless Business System + Generative Interface**

## 真实问题
传统企业 SaaS 把大量价值绑定在固定页面、菜单和表单上，但 Agent 已经能够理解用户意图并直接调用业务能力。

## 核心机制
前台 UI 逐渐由生成式交互替代，后台 SaaS 保留真正不可替代的部分：System of Record、权限、确定性业务规则、Workflow、API/Event。

## 为什么不是普通聊天入口
关键问题不是“CRM 里加 Claude”，而是用户是否还需要理解 CRM 的页面结构。如果 AI 能直接操作业务对象，UI 的价值会下降，后台状态和规则反而更重要。

## Composable Test
LLM + Salesforce API 很容易做 Demo；真正的结构变化来自把 SaaS 重新拆成 Headless Business System 与动态界面。

## 可迁移原则
> AI 时代企业软件的护城河可能从固定 UI 转向可信业务状态、规则、权限和事件层。

## 对 B/G 的启发
应急管理系统不必长期保留所有复杂后台页面。AI-native 工作台可以逐步接管主线操作，而原系统成为权威业务底座。

## 跟踪判断
**与你的桌面/插件工作台方向高度相关。**
