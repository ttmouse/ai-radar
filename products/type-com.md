# Type.com

**创新评分：★★★★☆**  
**模式：AI Work as Shared Artifact**

## 真实问题
大多数 AI 工作发生在私人聊天 Session 里：Context、工具调用、历史决策、生成物和执行轨迹都绑定个人。一旦需要团队协作，人就变成复制粘贴和同步层。

## 核心机制
把一次 AI 工作的 Session、Context、Memory、Tools、Artifacts、History 变成可以被团队共享、继承和继续执行的工作资产。

## 为什么不是普通协作文档
共享的不只是最终结果，而是“AI 如何得到这个结果”的可继续状态。

## Composable Test
聊天记录共享很容易；真正新的是将 Agent work state 产品化为可继承对象。

## 可迁移原则
> Agent 的工作状态应该像 Git repo 一样可交接，而不是像私人聊天一样封闭。

## 对本地 Agent / B/G 的启发
任务不应只关联一个对话链接，而应拥有 Context、Artifacts、执行记录、决策和下一步；换 Agent 或换人后仍可继续工作。

## 跟踪判断
**值得继续跟踪。**
