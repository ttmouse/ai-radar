# LapuAI

**创新评分：★★★★☆**  
**模式：Desktop Tool Use**

## 真实问题
大量真实业务软件没有完善 API，更不会专门提供 AI 接口。如果 Agent 只能调用结构化 API，就无法覆盖既有桌面软件和历史系统。

## 核心机制
让 Agent 通过桌面 GUI 直接理解和操作现有软件，把“没有 API”从绝对阻塞变成可降级处理的问题。

## 为什么不是普通 RPA
传统 RPA 依赖预先录制和固定 selector；视觉 Agent 可以根据界面语义和当前状态做开放判断。

## Composable Test
Computer Use 模型 + automation framework 可以拼，因此单独产品壁垒有限；但它代表重要能力边界。

## 可迁移原则
> 在 API 不完整的现实世界里，Agent 需要 API-first、GUI-fallback 的执行策略。

## 对你的桌面专家工作台启发
原系统有 API 的部分直接 API 重构；缺失或难接的后台能力可以先嵌入网页或 GUI 操作，不必一开始重做全部后端。

## 跟踪判断
**工程与渐进式改造价值高。**
