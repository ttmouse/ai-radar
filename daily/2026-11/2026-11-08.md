## 1. 重点观察：Tobira Site Agent（Observe；Tracking 4/5；Novelty 2/4）
来源：[Product Hunt 11/06 新版本](https://www.producthunt.com/products/tobira-ai?launch=tobira-site-agent)、[产品旧版本 2026-03-23](https://www.producthunt.com/products/tobira-ai/awards)。

**真实问题**：当用户让 ChatGPT/Claude 等代理替自己寻找商家、预约或采购，传统商家网站仍假设访问者是人，要求页面浏览、表单填写和人工跟进；机器访客缺少明确的服务能力与交易边界。

**旧工作流**：消费者或其 Agent 搜索网站→阅读页面→跳转表单/邮件→商家人工回复→预约或下单。

**新工作流（厂商主张）**：商家输入 URL，生成面向人和其他 Agent 的 Site Agent→访客 Agent 在已有聊天入口咨询、谈条件、预约或提交订单→线索通知商家 Telegram/Email。官方称 10 分钟可完成接入，并声称机器读取网站更快；这些速度主张没有独立验证。

**机制**：网站从“人操作的页面”向“对 Agent 可调用的业务能力入口”演化。Agent-to-Agent 协商如果能与商家的真实库存、价格、折扣权限、预约容量、交易确认联动，可能改变交互原语和业务对象。但目前公开材料没有证明这种权限和交易状态由确定性系统强制约束。

**Composable Test**：网页抓取/检索 + Agent + MCP/OpenAPI + CRM/日历/支付 API + Telegram 通知，1–2 天可以拼出限定场景的大部分体验。真正难的是可信的报价约束、身份、双边同意、可撤销授权、订单状态和异常恢复；尚无独立证据证明 Tobira 在这些方面建立了新的结构。因此不进入 Core。

**Human / AI / Software 分工**：Human 定义商家价格、政策、交易授权和例外；AI 解释商品与需求、生成协商提案；确定性软件校验报价、库存、权限、支付与订单状态。后者是推荐架构，不应误当已证实的 Tobira 实现。

**架构证据**：已确认的是公开产品说明、与 ChatGPT/Claude 等现有聊天入口协作的定位；Agent Runtime、Memory、工具协议、审批执行链、交易 Eval 的细节未知。

**与历史模式的关系**：#02 现有聊天入口、#09 无头系统生成接口、#22 Agent 身份、#26 Agent-facing System of Record 足以解释大部分设计；真正新增的行业应用是“商家对消费者 Agent 提供可协商服务”，而非独立 Pattern。

**可迁移**：B/G 服务不应只有给人看的门户，还可以提供受权限限制、可机器读取的服务能力与状态；应急管理的“隐患整改提交、证据补件、预约专家复核”可以抽象为受控业务动作。已有本地 Agent/Browser/MCP 时可直接复刻商品查询→报价提议→确定性校验→人工批准→创建预约的狭窄链路；不值得抄 Agent 社交网络、虚拟形象或泛化谈判话术。

**最大未知与反证**：如果所谓 Agent 交易只是聊天机器人生成邮件线索，最终仍需人工完成交易，则核心结构没有改变。需要真实跨 Agent 订单测试、权限越权测试、取消/改价场景和交易完成率。跟踪 4/5。

## 2. 第二观察：Turnstone（Observe；Tracking 3/5；Novelty 1/4）
来源：[Product Hunt 11/06](https://www.producthunt.com/products/turnstone)。

**真实问题**：用户已有多个 AI 订阅，但某一 Agent 达到使用限制后，任务中断。**旧→新**：手动切换工具、重新粘贴上下文→同一个 Agent 工作状态在不同模型/订阅/本地 Ollama 之间继续。创始人称 Mac+iPhone 可用，连接 Claude/ChatGPT/Cursor/Grok/API/本地模型，并可迁移已有机器人 Skills/Routines；关于纯 Ollama 的本地数据路径和 Composio 零保留属于厂商回复，未独立验证。

**Composable Test**：模型路由 + 统一会话状态 + provider fallback + Skills 文件可构成主要体验；#06/#11/#27 已覆盖。需要核实跨模型工具调用语义、审批状态和长期 Memory 是否保持一致；“同一对话继续”不等于“任务安全无损继续”。可在本地 Agent 做 provider failover 的小规模试验，测量状态恢复成功率与重复动作率；不复制整套 UI。维持 Observe，不新增 Pattern。

> **网站面向 Agent 开放，不等于 Agent 获得了可靠交易能力。真正的跃迁，是把可协商的意图和不可违反的业务规则分开：AI 负责理解与提议，确定性软件负责价格、库存、权限、状态和真实成交，人负责授权与例外。**
