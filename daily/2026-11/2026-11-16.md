## 1. 重点观察：ChatGPT Wallet（Observe；Tracking 4/5，Novelty 2/4）
**真实问题**：消费者 Agent 可以比较和选择商品，但跨越支付环节时，用户银行卡秘密、单笔交易授权、商户订单和银行风控必须各自保留边界。

**旧流程**：人搜索比较商品 → 人进入商户结账 → 人输入/选择付款方式 → 人核对并支付。此前的 Agent 往往只能完成选择和填表，最终支付仍由人接管。

**新流程（已公布产品设计）**：用户向 dot 委派购物 → Agent 准备商品与结账 → 用户检查商品、总额、卡片 → 用户通过面容/指纹等安全校验逐笔批准 → 支付网络提供代替真实卡资料的 token → 现有商户结账与银行网络处理交易。用户与商户直接交易，商户保留定价、履约、退货和客服职责。

**事实**：OpenAI 11/13 公布钱包；初期在美国面向符合条件的成年 Pro 用户和美国发行卡通过 dots 分批开放；与 Amex、Mastercard、Visa 合作；每笔购买需要人工审核和安全检查；使用支付 token；公开 Commerce Partner Playbook，建议商户提供准确商品信息、允许已签名 Agent 访问并协调支付风控。来源：https://openai.com/index/introducing-chatgpt-wallet/ 。

**尚未实现/未知**：按额度、品类、时间窗口预先委托购买是官方描述的未来方向，**不是当前已经交付的能力**。没有公开独立统计可证实实际成交成功率、支付拒绝率、退款争议率、攻击抵御、跨商户兼容性；具体 Token 生命周期、Agent Runtime/Memory/Approval 内部实现细节未知。不可把合作伙伴背书当作可靠性证明。

**Human / AI / Deterministic Software**：Human 定义购买意图、逐笔审查授权；AI 搜索比较、形成购买提案并操作结账；确定性支付/风控/订单系统负责支付 token、实际扣款、风控、商户订单与争议处理。模型不应掌握卡片原始秘密，也不能自行制造用户授权。

**关键机制**：购买提案与可验证授权记录分离，支付 token 将实际支付能力与模型上下文分离。不是“AI 自动付钱”这么简单，而是跨 Agent、用户、支付网络和商户的委托边界。

**Composable Test：未通过强创新门槛**。现有浏览器 Agent + 商户结账 + 支付服务商 tokenization + 逐笔用户确认/生物识别 + 审计日志，可在受限商户/沙箱中于 1–2 天组合出核心体验的演示。真实金融网络兼容和风控规模化很难复制，但**复杂商业集成 ≠ 新应用层机制**。因此维持 Observe。

**历史 Pattern 对照**：#15 Proposed Action as First-class Object、#22 Agent as First-class Identity、#26 Agent-facing System of Record、#13 Deterministic/Probabilistic Split 已覆盖核心结构。相对 11/08 Tobira 和 11/11 Business Agents 的新增是**实际支付授权与网络 token 的产品化边界**，不是新模式编号。只有未来推出可验证的规则化持续委托、可撤销额度、跨商户一致责任账本并经独立验证，才考虑重新评估。

**迁移原则**：把“AI 建议执行”和“确定性系统接受授权并产生副作用”拆成两个业务对象；对高风险动作保存 scope、金额/对象、有效期、审批人、业务状态、证据及撤销结果。

**本地 Agent 可复刻**：先用本地 Agent Runtime/浏览器/MCP + Mock Checkout + approval ledger 实现购物提案、确认、一次性 token、幂等扣款和审计；不值得复制金融钱包 UI、银行卡保管和支付网络集成。应急管理可映射为“AI 建议下发检查文书 → 专家确认具体对象/内容 → 业务系统校验权限与版本 → 产生可追溯文书”，不得将 Agent 自身确认视为法律/行政授权。

**最大反证与高估风险**：目前依旧每笔人工确认，可能只是现有支付 token 与审批 UI 的组合，真实节省的操作量有限。若交易成功率/纠纷处理没有明显改善，产品新颖性进一步下降。Tracking 4/5（商业落地及委托治理），Novelty 2/4（机制）。

**今日养料：Agent 可以提出交易，但不能拥有授权本身。** 高风险动作的最小可信单位是“具体动作提案 + 用户可核验授权 + 确定性系统执行记录”，不是模型的一句“用户已经同意”。将来如果从逐笔批准走向规则化委托，最重要的创新检验是可撤销的授权边界和真实交易证据，而非自动付款步骤更多。
