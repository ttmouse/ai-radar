## 重点观察：Groundwork — 用确定性边界保护人写的计划

英文首发与创始人细节：https://www.producthunt.com/products/groundwork-6
源码：https://github.com/ikenga-hq/groundwork

**真实问题：**Coding Agent 更新计划时可能重写用户手工补充的段落。聊天中要求“不要改”无法提供稳定保证。

**旧工作流：**人和 AI 共同写计划 → AI 重新生成整份文档 → 人手动比较并找回被覆盖内容。
**新工作流（创始人公开描述，未独立实测）：**Claude Code Skill 创建包含研究、设计、计划、跟踪与 HTML Board 的文件夹 → AI 生成内容置于有标记的区块 → Python 脚本比较区块与上次生成内容的哈希 → 若用户已修改生成区块则跳过并报告；区块外人写的文字保持不变。工作包有稳定 ID，可输出执行波次与 Claude Code Workflow。

**Mechanism Delta：**不是模型被提示“尊重人类修改”，而是确定性程序基于来源与变更痕迹限制可写范围。把“谁能覆盖哪段内容”变成文件内可执行的编辑协议。

**Composable Test：未通过强创新门槛。** Markdown 区块标记、hash、Python、Git、Claude Code Skill 能在 1–2 天复刻核心机制；其强点是清晰可靠的产品边界，而不是新的通用 AI 原生工作模式。历史 #12 Source→Self-maintaining Artifact、#13 Deterministic/Probabilistic Split、#21 AI Work as Shared Artifact、#30 Intent as Source of Truth 已覆盖主要思想。

**分工：**Human 维护意图与手写段落、批准更改；AI 生成研究、计划、执行建议；Deterministic Software 维护来源边界、hash、冲突检测与保留规则。

**已确认的公开信息：**Apache-2.0 开源、Python 标准库、五种 profile、hash 保护与 HTML board 是作者公开说明；是否完全按宣称执行尚需代码和真实样本验证。
**合理推断：**能减少 Agent 再生成时误覆盖人的修改。
**未知：**并发写入、文件移动、hash 失配后的合并策略、复杂文档语义冲突、实际采用率、长期 Eval；不应推断它有独立 Agent Runtime 或 Memory 系统。
**分析判断：**小而实用的可靠性设计，不构成 #31。

**可迁移原则：**人类编辑的内容与 AI 可再生内容需要明确来源与覆盖权限。对应 AI 原生研发：保护 PRD 人工决策、验收标准、架构例外；本地 Agent 直接实现区块级保护、差异报告、拒绝覆盖测试；应急管理：检查文书的专家确认字段不能被 AI 再生成覆盖。**不值得抄：**五种完整 profile、通用 Board UI 或再造项目管理系统。

**反证与风险：**hash 只证明字节变化，不证明内容正确；保护人写内容也可能固化错误；模型可能绕过标记编辑文件其他位置。需要用独立文件权限/patch validator 防绕过。
**跟踪价值：4/5；新颖度 2/4；证据成熟度 B-。** 下一步验证源码中的写入边界、手工修改冲突和绕过测试。

## 第二观察：Samiksa — 从读研究到复现实验
来源：https://www.producthunt.com/products/samiksa
11 月 20 日发布说明：将论文/博客重排成可提问的交互文档，主张每个结论可追溯来源；有代码/数据时在 sandbox 复现原结果、改变假设并比较；作者承认仍是 waitlist，演示使用样例论文和录制运行。

**真实问题：**读懂论文不等于验证论文结论。旧流程是阅读 → 人手工找数据/代码 → 本地重建环境 → 验证；新流程声称是问题驱动重排 → 溯源 → 一键复现基线 → 修改实验 → 产出新研究。
**Composable Test：**Notebook、LLM、RAG citation、沙箱与现有代码执行工具可以较快组合限定体验；尚未证明新产品原语。与 #10、#21、#24 重叠。**真正值得追踪：**“引用可追溯”升级为“证据可执行复现”，但仍需真实论文验证。
**事实：**公开的是产品主张和录制样例；**推断：**可降低实验复现门槛；**未知：**缺数据/代码如何处理、复现成功率、sandbox 依赖、结果可信性、审批与 Eval。跟踪价值 4/5，证据成熟度 C，Observe 不晋级。
**本地复刻：**论文+GitHub repo → 沙箱运行原实验 → 固定依赖和随机种子 → 对比报告；不要复制整个论文写作 SaaS。
**B/G 启发：**AI 检查的证据链不只应可点击查看，还应尽可能具备可复核的检查过程和可重跑的规则判断。
