## 1. 重点观察：Google Gemini Tasks（Observe，跟踪价值 4/5，机制新颖度 2/4）
**官方**：Google 2026-11-17 发布 “Put Gemini to work for you”：https://blog.google/innovation-and-ai/products/gemini-app/tasks-in-gemini-free-new-features/ 。同期媒体：https://www.theverge.com/tech/1035756/google-spark-ai-tasks-free 。

**真实问题**：家庭和个人的事务横跨邮件、日历、网站、电话、支付和账号登录。传统聊天助手只能给出建议，人必须把建议转成真实的跨渠道操作。

**旧工作流**：人搜索维修商家 → 打电话询问 → 对比时间与日历 → 登录账号 → 付款/预约 → 核实结果。

**新工作流（官方展示）**：用户在 Gemini 切换 Chat→Task 或通过邮件/短信委派 → Agent 读取授权的个人上下文 → 在隔离执行环境中并行联系商家、浏览网页、使用保存的账号信息 → 在敏感交易节点请求确认 → 写入日历或执行支持的支付。官方举例是联系两家汽车维修店并预约；另举例通过 Google Password Manager 分析账单、通过 Google Pay 购买配件。

**关键产品机制**：
1. 将聊天入口与任务委派入口显式区分：从回答转向可持续的工作。
2. 以用户已有的邮件、日历、支付、账号为跨系统上下文与执行能力；不是把全部凭据放进模型提示词。
3. 通过商家电话交互将原本缺乏 API 的线下服务转为可委派工作；官方称通话会披露 AI 身份，商家可退出。
4. 采购场景引入 AP2、支付 token 和预设支出上限，敏感操作仍有授权边界。
5. 每账号硬件隔离虚拟机的表述来自官方，具体实现和独立安全性未知。

**事实/推断/未知**：
- 已确认：Google 11/17 公告 Chat→Task、更广免费覆盖、美国起步的高级操作、电话、Google Pay、密码管理器、硬件隔离和授权机制；这是厂商功能声明。
- 合理推断：个人生态原生数据与执行权限降低上下文搬运成本；电话成为非 API 商家的 Agent 工具。
- 未知：真实任务成功率、人工接管比例、授权误判率、商家退出率、端到端状态一致性、内部 Runtime/Memory/Eval/Approval 细节。单个厂商 Demo 不证明普遍效果。
- 分析判断：入口和权限整合可能很有商业价值，但并不自动构成新的产品机制。

**Composable Test**：在限定场景，Agent Runtime + browser + 电话 API + Gmail/Calendar + 支付沙箱 + 人工审批，可以在 1–2 天组合 80% 可见体验。Google 的独特优势是用户规模、生态权限、账号/支付信任、跨站兼容性；这些是交付壁垒，不等于新交互原语。故不晋级 Core。

**Human / AI / Deterministic Software**：
- Human：给目标、预算、账号/支付授权，处理例外。
- AI：解析意图、规划、搜索、电话沟通、选择候选行动。
- Deterministic Software：登录凭据、支付 Token、授权校验、日历写入、任务状态、回执与撤销。实际强制执行覆盖率尚未独立验证。

**与历史模式对比**：#03 Goal→Autonomous Work、#06 Persistent State、#09 Headless System、#14 Governance、#15 Proposed Action、#22 Agent Identity、#26 Agent-facing System of Record、#27 Context Belongs to Work 均能解释主要机制。真正新增的是这些模式在大规模个人生态与非 API 商家电话通道中的组合交付，不新增 #31。

**可迁移原则**：Agent 可完成的任务边界由“它能理解什么”与“它能被授权触达什么真实状态”共同决定。电话等非结构化接口可以补充 API，但完成判定仍应依赖可验证的业务回执。

**对 AI 原生研发、本地 Agent、应急/B/G**：本地优先做统一 Task Ledger + 浏览器/邮件/日历/电话工具 + 凭据隔离 + 操作审批 + 结果验证；可用模拟电话与测试日历完成实验。应急管理可让 Agent 联系责任主体确认整改、安排专家复核，但“电话答应整改”不等于“隐患闭环”，必须回到权威业务状态。不要复制大规模个人生态、支付网络或全平台 App。

**反证/高估风险**：如果大部分用户任务仍需要人工频繁接管，或者跨商家真实完成率不稳定，产品主要仍是多工具自动化包装；不能因 Google 发布和免费覆盖就晋级机制创新。下一次跟踪独立任务完成率、电话商家配合、授权边界与可撤销持续委托。
