## 核心产品：Claude Code Projects

### 真实问题
Coding Agent 单任务能力越来越强，但持续项目仍要求人反复重建 Context、拆分工作、管理多个 Session、追踪依赖。人的瓶颈从写代码迁移成 Agent 调度。

### 旧工作流
Project → Human 拆任务 → Session A / B / C → Human 重建 Context、跟踪状态、汇总结果。

### 新工作流
Human → Persistent Project Coordinator → 自动创建/路由 Worker Threads → branch / PR / CI → 状态回流 Project → 只把 review / blocked / approval 等事项交还 Human。

### 核心机制
重点不是并行 Agent，而是 Project 成为 Persistent Coordination Object：长期目标、共享 Context、Memory、Workstreams、Artifacts、状态和人的注意力队列都归属于 Project；Agent Session 只是临时执行资源。

### Composable Test
并行 Claude Code、git worktree、CI、MEMORY.md、任务队列都能快速拼装，因此不把 Multi-Agent 当创新。值得入选的原因是一级交互对象发生变化：用户持续 brief Project-level Coordinator，而不是自己管理每个 Session。

但这仍主要是既有模式的成熟组合，所以不新增 Pattern。

### Human / AI / Software
Human 维护目标和关键判断；Coordinator 维护 Project-level state 并路由；Worker 执行具体任务；Git / branch / PR / CI 等确定性软件负责 artifact 与验证状态。

### 与历史模式比较
Pattern 03 Goal → Autonomous Work：提供持续目标执行。
Pattern 17 Judgment Queue：Overview 聚合 Ready for review / Waiting on you。
Pattern 27 Context Belongs to Work：最核心，Context 属于 Project 而非 Session。
Pattern 28 Generation as State Transition：Worker 执行持续改变 Project state。

今天没有新的一级模式。真正新增的是更强的产品证据：Project 正在替代 Chat / Agent Session，成为 AI 原生软件的一级工作对象。

### 对本地 Agent / B/G 的启发
长期目标不应实现成一个永不结束的聊天。更好的对象模型：Project = Goal + State + Memory + Workstreams + Artifacts + Decisions + Human Attention Queue。Session 只是 Project 按需创建的 Worker。

对应应急工作台，一个周期目标可以是 Project；AI看、视频看、现场看、隐患验收是 Workstreams，而不是四个彼此割裂的入口。

### 可复刻路径
用 project.json + memory.md + workstreams/ + structured worker result + attention_queue + Git/filesystem 即可验证 V0。不要先造多 Agent UI，也不要把所有原始对话塞进共享 Context。

### 未知与反证
它可能只是 Linear + git worktree + Claude Code + shared memory 的高质量整合。长期 Memory 的漂移、遗忘、版本、冲突和 Coordinator 错误扩散仍未被证明解决。

## 主动淘汰 / 观察
- Comp AI：持续合规 Agent 有商业价值，但当前看到的是 Agent + compliance workflow + integrations 的纵向自动化，没有发现新的一级产品机制，观察。
- Google Home MCP：重要的平台开放动作，但 MCP 接入本身明确不构成产品创新，淘汰。
- AI agent hotlines：Agent 可举报其他 Agent 是新的安全治理实验，但更接近安全基础设施/研究机制，尚不足以形成通用应用层产品模式，观察。
- HiddenLayer：Agent/tool security 重要，但主要属于安全基础设施，不进入应用层模式库。

## 今日产品创新养料
> 长期 AI 工作的核心对象不应该是“一个更长的聊天”，而应该是持续存在的 Work / Project。Goal、State、Memory、Artifacts 和 Human Attention 属于工作；Agent Session 只是可创建、替换、并行和销毁的执行资源。
