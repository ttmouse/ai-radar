# AI 应用创新雷达 — 2026-09-22

## 结论

今天没有发现达到核心创新标准的新产品。

核心入选：0。新增 Pattern：0。

今天的搜索反而强化了一条筛选边界：**Agent 能做更多事情，不等于软件的基本组织方式发生变化。** 当前大量发布仍集中在 Agent Runtime、MCP、自治执行、垂直工作流和 Agent 基础设施上；这些能力重要，但如果没有改变业务对象、Human-in-the-loop、证据/权限结构或人的注意力分配，就不进入核心库。

## 今日最值得观察：Meta Muse 与 Amazon 的冲突

The Verge 9 月 21 日报道，Amazon 阻止 Meta Muse 代表用户访问 Amazon 购物，理由涉及未授权活动、隐私和安全；报道还指出争议之一是 Muse 在浏览时没有明确标识自身 Agent 身份。

这不是一个新产品机制，但它给 Pattern 22「Agent as First-class Identity」提供了更强的现实反证：**Agent 拥有身份不能只在用户侧成立；对方系统也必须能够识别、授权、限制和追责这个 Agent。**

真正的问题从：

`User → Agent → Website`

升级为：

`User delegates authority → Agent presents identity + scope → Counterparty verifies/accepts → Action → Audit/dispute`

如果对方系统无法确认“谁在行动、代表谁、授权到什么范围”，所谓自主 Agent 在跨组织场景里仍然只是模拟人的浏览器自动化。

### Composable Test

这个现象本身不新增 Pattern。Agent identity、scope、approval、audit 已经被 Pattern 22 覆盖。Amazon/Muse 只是暴露出一个此前容易忽略的边界：**身份必须是双边可验证的协议，而不是 Agent 自己声明。**

## 候选筛选

### Meta Muse — 观察，不入选

值得跟踪的是它与外部平台的权限冲突，而不是“会购物”本身。购物 Agent 可由 browser automation + memory + approval + payment 拼出，无法通过核心 Composable Test。

### SereneDB Krummelanke — 淘汰

9 月 22 日发布的实时搜索/分析数据库，定位于大量 AI Agent 的高频企业数据查询。它可能是有价值的 Agent 基础设施，但属于数据库/数据基础设施，不是应用层产品机制创新。

### Google Home MCP — 继续淘汰

允许第三方 Agent 访问和控制智能家居是重要平台开放动作，但 MCP / Tool Exposure 本身不是产品机制创新。此前判断不变。

### Instinct — 继续观察

跨邮件、消息、日历、设备音频、位置和屏幕执行任务，产品能力强，但目前公开结构仍可由 persistent personal agent + broad context + tools + approval 解释。更值得观察的是它是否形成新的授权/隐私对象，而不是继续增加可执行工具。

## 对 AI 产品设计 / 本地 Agent / B/G 的启发

对本地 Agent，最值得补的不是更多 Browser Tool，而是显式的 Delegation Envelope：

- principal：Agent 代表谁；
- agent identity：哪个 Agent 在行动；
- scope：允许做什么；
- resource boundary：可访问哪些对象；
- time / spend limit：有效期和额度；
- approval policy：哪些动作必须回到人；
- evidence：动作依据；
- audit / revoke：如何追踪和撤销。

对应应急管理，如果未来 Agent 代表专家、企业安全员或政府人员执行动作，不能只依赖登录 Cookie。系统必须知道：**这是本人操作，还是 Agent 代理操作；Agent 代表哪个责任主体；授权范围是什么；最终责任落在哪里。**

这比“让 Agent 能点后台”重要得多。

## 今日产品创新养料

> 真正的 Agent Identity 不是给 Agent 一个账号，而是让委托关系能够被交易对手验证。

当 Agent 开始跨组织行动，软件必须从“识别用户”升级到“识别 principal + agent + delegation + scope”。否则自主 Agent 只是带着用户 Cookie 的自动化脚本。
