## Observe：1Password for Claude

Tracking 4/5，Novelty 2/4，Evidence B。

[7 月官方发布](https://1password.com/press/2026/july/1password-for-claude)；[8 月安全文档](https://support.1password.com/1password-claude-security/)；[本轮报道](https://www.theverge.com/ai-artificial-intelligence/1016399/1password-ai-agent-password-sign-in)。

**真实问题**：浏览器 Agent 登录时，过去需要用户接管或共享登录信息。

**新工作流**：Agent 请求 → 人批准指定账户 → 独立软件完成登录 → Agent 接收结果。官方确认按会话隔离、填充时暂停 Agent 页面观察、失败后清理字段；机制并非本周首次出现。

**分工**：Human 批准；AI 请求并继续任务；Software 处理敏感登录过程。**边界**：登录后的业务行为不由密码管理器负责。

**Composable Test**：浏览器扩展、审批和会话管理可以组合主体验。#14/#15/#16/#22 已覆盖。**本地 Agent** 可复刻按会话授权；不必重造密码管理器。**B/G** 应对正式业务写操作单独校验。最大未知是多站点可靠性及授权后风险。

## Observe：Neo4j Context Engine

Tracking 4/5，Novelty 2/4，Evidence C/B。

[10 月 19 日官方说明](https://neo4j.com/blog/news/neo4j-context-engine/)；[产品页](https://neo4j.com/product/context-engine/)。

**问题**：组织术语、流程、数据分散，Agent 各自重建上下文。**新流程**：六层本体连接业务概念、流程、数据、系统、工具和运行知识，通过 API/MCP 共享。官方确认 Context Studio、GraphRAG、关联记忆；仍为 Private Preview。

**Composable Test**：知识图谱 + RAG + MCP 可以复刻主线，#04/#19/#25/#27 已覆盖。**本地 Agent** 优先在 SQLite 中补充类型化关系、来源和可信度；无需先迁移数据库。未知：跨系统语义冲突、学习质量和真实部署效果。
