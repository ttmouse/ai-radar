## Observe 1：OpenScreen 2

官网：https://getopenscreen.com/
技术文档（10 月 13 日更新）：https://getopenscreen.com/docs/ai-editing/
源码：https://github.com/getopenscreen/openscreen
Product Hunt：https://www.producthunt.com/products/openscreen-2

Tracking 4/5；Novelty 2/4；Evidence B；Composable but not independently novel。

**旧流程**：人录制像素视频，手动寻找点击、停顿、重点位置，逐项编辑时间线。
**新流程**：软件记录像素 + 独立鼠标轨迹/点击事件 + 本地转写；确定性规则安排 zoom shots；Agent 读取时间线和转写，调用真实编辑工具，用户预览、撤销、导出。

**事实**：点击驱动自动 zoom 无需 AI；内置 Agent 与 MCP 可调用 trim、zoom、blur、clip 等非破坏性操作。内置 Agent 支持同时回退项目、对话和 Agent 状态。MCP server 默认只读，需另开 MCP edits；编辑非当前项目依赖 checkpoint，最多保留 20 个且仅在内存中。官方文档明确指出通过 stdio 启动的 MCP 进程以用户权限运行，不受 MCP edits 开关限制。

**Mechanism Delta**：视频从像素产物变为 pixels + events + transcript + editable timeline 的可操作对象。Human 从逐项剪辑转为目标/审核/回退；AI 从给建议转为选择 typed edits；Software 负责确定性编辑、版本和权限。

**Composable Test**：录屏事件 + Whisper + 编辑器 API + MCP + Agent 在 1–2 天能实现主要演示；生产级跨平台渲染和可靠回滚更难，但 #01、#10、#13、#21 已能解释结构，因此 Observe 而非 Core。

**事实与推断**：已确认的是官方功能和限制；推断是事件层能降低视觉定位成本；未知是复杂剪辑成功率、跨重启恢复能力和独立安全审计。

**本地 Agent/应急启发**：将图像/视频证据保存为原始素材 + 时间/点位 + 检查点 + 结构化事实 + 批注 + 变更记录。AI 生成可审计的对象级变更，确定性软件验证版本、权限、回滚。先对 20 个真实样本做复核耗时、定位准确率、撤销成功率比较。不应复刻完整录屏渲染器。

**最大反证**：UI Undo 不等于跨会话/跨重启可恢复；同一工具在 MCP server 与 stdio 两种接入模式下的权限边界不同。跟踪 4/5。

## Observe 2：Shop MCP

2026-10-13 官方：https://shopify.dev/changelog/posts/add-shopping-and-shop-pay-checkout-to-any-agent-with-shop-mcp

Tracking 4/5；Novelty 2/4；Evidence A/B。官方称单一 MCP 接入提供 17 个工具，覆盖超 10 亿商品，支持搜索、购物车、用户登录偏好、确认后结账、订单查询。非 Shopify 店铺支付由用户在 Shop 中授权后提供一次性卡信息。商户订单仍保留在原有系统；首发无 webhook，需轮询结账状态。

**Mechanism Delta**：Agent 可跨商户完成发现到交易，不必依赖页面解析。**Composable Test**：主要是成熟商品/支付系统的 Agent 接口，2026-09-28 已有 WebMCP checkout。强化 #26 Agent-facing System of Record、#22 Agent Identity、#15 Proposed Action，非全新 Pattern。对 B/G 系统启发：Agent 负责发起，正式业务记录和高风险授权仍归原系统与责任主体。

## 今日创新养料
