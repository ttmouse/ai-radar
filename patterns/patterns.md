# AI 原生产品模式库

| # | 模式 | 代表产品 | 核心变化 |
|---:|---|---|---|
| 01 | Human Signal + Machine Context | Granola | 人提供注意力信号，机器利用完整上下文补全 |
| 02 | Existing Surface → AI Action Layer | Acti | AI 消失进已有高频交互表面 |
| 03 | Goal → Autonomous Work | ChatGPT Work / Claude Cowork | 从问答转为持续执行目标 |
| 04 | Organization Context Layer | Atlas | 公司上下文成为多个 Agent 共用基础层 |
| 05 | AI Build → Software Run → AI Repair | Airtop | AI生成并维护确定性自动化 |
| 06 | Persistent State → Proactive Action | Fambot | AI持续维护状态并主动行动 |
| 07 | Recorder → Participant → Worker | Fireflies | AI从记录过程进入过程并承担工作 |
| 08 | Observe → Detect Pattern → Propose Automation | Tadata | AI主动发现应该自动化什么 |
| 09 | Headless System + Generative Interface | Claudeforce | 传统 SaaS 退为数据/规则/权限层 |
| 10 | Artifact → Semantic Object → Action | Gemini Spark × Photos | 文件被理解后直接进入工作流 |
| 11 | Capability-on-Demand | Monid | Agent按任务动态发现和获取能力 |
| 12 | Source → Self-maintaining Artifact | Browzer | 派生产物持续与 Source of Truth 对齐 |
| 13 | Deterministic / Probabilistic Split | Nex / Airtop | 确定性给软件，不确定性给模型 |
| 14 | Agent Workspace + Governance Layer | Meta Muse | 执行环境和治理层分离 |
| 15 | Proposed Action as First-class Object | Relaticle | AI动作先成为可审核业务对象 |
| 16 | Context Supply Chain | AIR Security | 持续治理 Skill/MCP/外部上下文信任链 |
| 17 | AI Work Queue / Judgment Queue | Quincy Hub | 人的工作入口变为判断和例外处理 |
| 18 | Spatial Agent Supervision | 49agents IDE | 空间用于管理大量 Agent 注意力 |
| 19 | Organization Learning Loop | WRITER Enterprise Brain | 组织日常工作持续沉淀为共享 Memory |
| 20 | Agent Operations Agent | Typewise Nova | AI持续运营、评估和改进其他 Agent |
| 21 | AI Work as Shared Artifact | Type.com | AI 工作状态成为团队可继承资产 |
| 22 | Agent as First-class Identity | Thousand | Agent拥有独立身份、scope和审计 |
| 23 | Adversarial Agents + Independent Referee | OpenMarket | 把利益冲突编码进 Agent 架构 |
| 24 | Evidence Gap → Active Investigation | HyperVerge | AI发现证据缺口后主动调查 |
| 25 | Business Semantic Layer | OpenAI Data Agent | AI共享组织对数据的统一业务语义 |
| 26 | Agent-facing System of Record | Accordio | SaaS成为 Agent 的可信状态和确定性动作层 |
| 27 | Context Belongs to Work | Switch | Context 属于任务/项目/Room，而非某个 Agent |
| 28 | Generation as State Transition | Diiverge | AI生成推动持久状态演化，而非一次性输出 |
